# Footie Club Manager

A deep football club manager for phone and tablet (Flutter), from the maker of Football Nations Manager (FNM).

This repo starts with the **design package** for Claude Design:

- `DESIGN_BRIEF.md`: the product and design brief (screens, components, constraints, open questions).
- `design/fnm_inspiration/`: screens from FNM 1.1.1 (phone + iPad) as reference for density, flow and tone. See its README.
- `docs/FNM_GAME_OVERVIEW.md`: every FNM system and what it becomes in a club manager.
- `docs/FNM_MATCH_ENGINE.md`: how FNM decides and draws a match (live engine, background sim, 2D pitch) and what can be reused.

All clubs, players and competitions are fictional. Countries and cities are real.
